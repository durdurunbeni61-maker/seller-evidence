# Agent instructions

Keep this public project generic, offline and independently usable. The source
shop's private repository, history, data and commercial rules are out of scope.

- Never read or copy production databases, raw exports, customer messages or files.
- Fixtures are invented and explicitly labeled fictional.
- No scraping, network clients, marketplace writes or automatic publishing.
- No real local paths or credentials in source or documentation.
- Report only features proved by execution; mark hosted CI as unrun until it runs.
- Keep runtime free of third-party dependencies unless a justified, reviewed change
  is approved. License-unknown code must not be included.
- Run README examples, tests and `scripts/check_release.py` before release.
- Obtain owner approval of the exact destination and file manifest before public
  publication. Do not alter another repository's visibility or move its history.
