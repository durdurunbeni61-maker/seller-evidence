# Contributing

This project is early-stage. Small, tested changes and bug reports with fictional
reproductions are welcome once the public repository is created.

1. Install from the source checkout using the README.
2. Use a feature branch; run the documented tests and release guard.
3. Use invented fixtures only. Never attach real seller exports or customer data.
4. Document current behavior and limitations; distinguish planned work.
5. Add tests for missing/zero values, invalid CSVs, scope boundaries and storage
   conflicts when changing those behaviors.

Runtime must remain offline. Do not add scraping, marketplace writes, automatic
publishing, telemetry or code that submits data to an AI provider. Dependencies
need a justified purpose and license review. Preserve third-party notices.

By submitting a contribution, you confirm you have the right to submit it under
this project's MIT license. Do not copy code whose license/provenance is unknown.
No contributor license agreement or transfer of ownership is required.
